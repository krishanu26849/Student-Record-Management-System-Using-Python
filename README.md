# Student Record Management System

A simple Python-based desktop application for managing student records using a graphical user interface and SQLite database.

## Project Overview

The **Student Record Management System** allows users to manage student information through an easy-to-use desktop interface. Users can add, view, search, update, and delete student records.

The project is developed as a practical application of concepts covered in the **CSE3011 Python Programming** course.

## Features

* Add new student records
* View all student records
* Search students by ID or name
* Update existing student information
* Delete student records
* Export student records to CSV
* Input validation
* Exception handling
* SQLite database storage
* Simple Tkinter graphical interface

## Technologies Used

* **Python**
* **Tkinter** – Graphical User Interface
* **SQLite3** – Database
* **CSV** – Data export

## Student Information

The system stores:

* Student ID
* Name
* Age
* Course
* Email
* Marks
